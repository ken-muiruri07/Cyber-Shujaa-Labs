# Cyber Shujaa Security Labs

This repository contains documentation of cybersecurity labs completed during the Cyber Shujaa Security Analyst training program.

The labs cover:
- Linux system fundamentals
- Network analysis basics
- SQL queries and data handling
- Introductory security investigation techniques

## Purpose
To demonstrate hands-on learning in cybersecurity fundamentals and structured problem-solving through practical lab exercises.

## Focus Areas
- SOC fundamentals
- System and log analysis
- Linux CLI proficiency
- Basic incident response thinking
